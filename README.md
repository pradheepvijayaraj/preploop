# PrepLoop

**Open PYQs. Focused practice. Privacy built in.**

PrepLoop is an open-source app that helps you prepare for exams. It brings
previous-year questions into a focused workspace for practice, timed tests,
search, and review, with offline access, simple organisation, and privacy built
in.

UPSC CSE is the first available archive, with **393 papers and 6,200 questions**
across Prelims and Mains. PrepLoop is built to support more exams over time.

[Download PrepLoop](https://github.com/utilinlabs/preploop/releases)

## Features

- Previous-year papers organised in one searchable library
- Practice mode with optional instant answer feedback
- Timed tests with pause, flags, navigation, and auto-submit
- Fast offline search across topics, phrases, papers, and subjects
- Scores, answer review, topic breakdowns, and retakes
- Focused Mains reader with marks, subparts, diagrams, and mathematical notation
- Flags, filters, test history, and saved preferences
- Light and dark themes
- Your answers, results, and settings stay on your device
- In-app updates on macOS, Windows, and Linux
